# 請求書ジェネレーター

インボイス制度(適格請求書)と源泉徴収に対応した、日本語の請求書作成ツールです。
**登録不要・ブラウザ内で完結**し、出力するPDFに透かしやロゴは一切入りません。

> 公開中(2026-07-31 にオーナー承認のうえ本番公開)。https://invoice-tool-kohl.vercel.app

## 特徴

- **透かしなしのPDF** — 無料のまま、取引先へそのまま送れる完成品を出力します
- **適格請求書に対応** — 登録番号欄と、税率ごとの区分集計を標準で備えます
- **端数処理は税率ごとに1回** — 明細行ごとには処理しません(インボイス制度の要件)。切り捨て / 四捨五入 / 切り上げを選べます
- **源泉徴収を自動計算** — 100万円以下 10.21%、100万円超 20.42%(復興特別所得税を含む)。行単位で対象・対象外を切り替えられます
- **入力内容を送信しない** — サーバーを持たず、すべて端末内で処理します
- **書き出し** — PDF(印刷)/ CSV(Excel対応)/ JSON(入力データの保存・再読込)
- **4種類の書類** — 請求書 / 見積書 / 納品書 / 領収書。`/?type=estimate` のように種別を指定して開けます
- **収入印紙の判定** — 領収書に貼る印紙を `/inshi` でその場で判定します。5万円の境界だけでなく、消費税額の区分記載・電子交付・クレジットカード、そして**免税事業者だけ結論が変わる点**まで扱います
- **送付状** — 紙で郵送するときに添える1枚を `/soufujo` で作ります。頭語と結語の対応(拝啓→敬具 / 前略→草々)と、同封物の「記〜以上」をそろえます
- **封筒の宛名** — `/atena` で長形3号(三つ折りのA4が入る封筒)の表面と裏面を縦書きで刷ります。「御中」と「様」を重ねない敬称、住所の漢数字、「請求書在中」の朱書きをそろえます。郵便番号の赤枠への位置合わせはしていません
- **催促状** — 支払期日を過ぎても入金がないときの1通を `/saisoku` で作ります。1回目(行き違いを想定し、請求書の再送を申し出る)と2回目(経過日数を数字で書く)を分け、どちらも曜日つきの回答期限で閉じます。遅延損害金や法的手続きの文面は扱いません
- **開業挨拶状** — 開業・独立を知らせるはがきの文面を `/aisatsujo` で縦書きに刷ります。時候の挨拶は差出日の月で1つに決め、日付は令和の漢数字、句読点は打たない慣例を既定にします。文面がはがきに収まらなければ文字を小さくし、それでも収まらなければ警告します。宛名面は刷りません
- **出金伝票** — 領収書が出ない支払い(交通費・自販機・香典など)を `/shukkin` で1件1枚の伝票にし、A4に3枚ずつ並べて刷ります。番号は続きから振れます。勘定科目は書いたとおりに出すだけで、候補は出しません(経費になるか・どの科目かは判断しません)
- **入金伝票** — 現金で受け取った代金・立替金の返金などを `/nyukin` で1件1枚の伝票にし、出金伝票と同じ形でA4に3枚ずつ並べて刷ります。科目の候補は出しません
- **経費精算書** — 立て替えた交通費・備品代などを `/keihi` で1枚に15行まで並べ、合計と仮払金の差引(支給額/返金額)を出してA4縦1枚に刷ります。経費になるか・勘定科目は判断しません
- **支払明細書** — 外注先・業務委託への支払いの内訳を `/shiharai-meisai` で1枚に10行まで並べ、合計から差し引くもの(源泉所得税・振込手数料など、入れてもらった額)を引いた差引支払額を出してA4縦1枚に刷ります。源泉徴収の要否・消費税・インボイスの代わりになるかは判断しません
- **見積依頼書** — 外注先・仕入先に値段を聞くときの1枚を `/mitsumori-irai` で作ります。品名・仕様・数量を10行まで並べ、回答期限・希望納期・納入場所・支払条件を添えてA4縦1枚に刷ります。金額の欄は持たず、数量と単位は書いたとおりに出します。契約の成否や支払条件の妥当性は判断しません
- **業務完了報告書** — 業務委託の仕事を終えたときの1枚を `/kanryo-hokoku` で作ります。件名・作業期間・完了日と、行った作業・成果物を10行まで並べてA4縦1枚に刷ります。相手が確認日と名前を書く確認欄をつけられます(中は常に空欄)。金額の欄は持たず、検収が済んだか・契約どおりかは判断しません
- **実務の解説記事を同梱** — 書き方・計算方法の解説ページをツールとセットで持ち、検索からの入口にします

## 画面

左に入力フォーム、右にA4のリアルタイムプレビューを並べた2ペイン構成です。
「PDFとして保存 / 印刷」からブラウザの印刷ダイアログを開き、A4 1ページのPDFとして保存できます。

## 技術構成

依存パッケージ **0** の静的サイトです。ビルド工程は1つだけあり、
広告の設定値を環境変数から静的ファイルへ書き出します(`tools/build-ads.mjs`)。
**値が未設定なら「未設定」を書き出して正常終了する**ので、ビルドが本番を止めることはありません。

| 項目 | 内容 |
|------|------|
| フロントエンド | 素の HTML / CSS / JavaScript(ES2020) |
| PDF出力 | ブラウザの印刷機能(`@media print` によるA4レイアウト) |
| データ保存 | localStorage(端末内のみ) |
| ホスティング | Vercel(静的配信) |
| テスト | Node.js 標準の `assert` のみ |

## セットアップ

ビルドは不要です。`public/` を任意の静的サーバーで配信してください。

```bash
python -m http.server 8891 --directory public
```

http://localhost:8891 を開きます。

なお本番(Vercel)は `cleanUrls` を有効にしているため、記事のURLは `/guide/seikyusho-kakikata` のように
拡張子なしになります。上記のローカルサーバーは拡張子を省略できないため、
ローカルで記事を開くときは `/guide/seikyusho-kakikata.html` を指定してください。

## テスト

```bash
node --test tests/*.test.js
```

合計 **115件**(calc 18 / cover 26 / stamp 17 / links 12 / seal 12 / ads 15 / soufujo 8 / print 7)。

`calc.test.js`(18件)は消費税の端数処理、複数税率の集計、源泉徴収の計算、登録番号の形式検証を扱います。
期待値は国税庁タックスアンサー(No.6625 / No.2795)に基づいています。

`stamp.test.js`(17件)は印紙税の判定を扱います。税額表の全区分は No.7141 の原文と照合しており、
**5万円ちょうどは課税**という境界と、**課税事業者と免税事業者で結論が変わる**ケースを固定しています。

`print.test.js`(6件)は、印刷時に合計欄と振込先がページをまたいで割れないための `break-inside: avoid` が
`@media print` の中に在り続けることを確かめます。

`links.test.js`(12件)はサイトの構造を固定します。**ツールが出せる4種類の書類(請求書・見積書・納品書・領収書)に、
それぞれ入口となるページが在ること**と、**母屋 `/kaigyo` から全工程へリンクが在ること**を含みます。
2026-09-02 まで、納品書は出力できるのに入口が1つも無い状態でした。

`cover.test.js`(26件)は送付状の文面を扱います。頭語と結語が対になること、
**「前略」のときは時候の挨拶を出さないこと**、同封物が0件なら「記〜以上」を出さないことを固定しています。

`soufujo.test.js`(8件)は、送付状ページの HTML・JS・CSS の読み合わせです。
`soufujo.js` が触る id が HTML に無い、といった「開いた瞬間に真っ白になる」壊れ方を落とします。
⚠ 描画そのものは確かめていません(横あふれ・改ページ・印刷の見た目は対象外)。

`ads.test.js`(15件)は広告の一線を固定します。**書類を作る画面と `/legal` に広告を置かないこと**、
**印刷時に器そのものを消す規則が `no-print` とは別に在ること**、そして
**書類を作る画面の CSP が `connect-src 'none'` のままであること**を含みます。
「入力内容を送信しない」という約束は文章だけでなくヘッダでも止まっている必要があり、
広告のための緩和は記事と母屋の2面に閉じ込めてあります。
⚠ このテストは `tools/build-ads.mjs` を実際に走らせるため、実行中に `public/ads-config.js` と
`public/ads.txt` を書き換えます(最後に未設定の状態へ戻します)。

## 料金の考え方

**全機能が無料です。有料プランの予定はありません**(2026-08-09 決定)。PDFの出力は無料・透かしなしを維持します。

以前は「何度も作る人の手間を減らす機能」(マスタ保存・自動採番・発行履歴・見積書→請求書の変換)を
有料機能とする方針でしたが、**課金候補の検索需要を実測した結果、いずれも想定していた需要が確認できなかった**ため
取り下げました。経緯は [docs/仕様.md](docs/仕様.md) を参照してください。
