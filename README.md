# 請求書ジェネレーター

インボイス制度(適格請求書)と源泉徴収に対応した、日本語の請求書作成ツールです。
**登録不要・ブラウザ内で完結**し、出力するPDFに透かしやロゴは一切入りません。

> 開発中(未公開)。本番公開はオーナー承認後に行います。

## 特徴

- **透かしなしのPDF** — 無料のまま、取引先へそのまま送れる完成品を出力します
- **適格請求書に対応** — 登録番号欄と、税率ごとの区分集計を標準で備えます
- **端数処理は税率ごとに1回** — 明細行ごとには処理しません(インボイス制度の要件)。切り捨て / 四捨五入 / 切り上げを選べます
- **源泉徴収を自動計算** — 100万円以下 10.21%、100万円超 20.42%(復興特別所得税を含む)。行単位で対象・対象外を切り替えられます
- **入力内容を送信しない** — サーバーを持たず、すべて端末内で処理します
- **書き出し** — PDF(印刷)/ CSV(Excel対応)/ JSON(入力データの保存・再読込)
- **4種類の書類** — 請求書 / 見積書 / 納品書 / 領収書

## 画面

左に入力フォーム、右にA4のリアルタイムプレビューを並べた2ペイン構成です。
「PDFとして保存 / 印刷」からブラウザの印刷ダイアログを開き、A4 1ページのPDFとして保存できます。

## 技術構成

依存パッケージ **0**、ビルド工程 **なし**の静的サイトです。

| 項目 | 内容 |
|------|------|
| フロントエンド | 素の HTML / CSS / JavaScript(ES2020) |
| PDF出力 | ブラウザの印刷機能(`@media print` によるA4レイアウト) |
| データ保存 | localStorage(端末内のみ) |
| ホスティング | Vercel(静的配信) |
| テスト | Node.js 標準の `assert` のみ |

```
public/
  index.html   入力フォーム + A4プレビュー
  app.js       画面制御・描画・書き出し
  calc.js      金額計算ロジック(DOM非依存・テスト対象)
  style.css    画面表示とA4印刷レイアウト
  legal.html   免責事項・プライバシーポリシー
tests/
  calc.test.js 計算ロジックのテスト
docs/
  仕様.md              機能仕様と課金方針
  セキュリティレビュー.md 公開前レビューの記録
```

## セットアップ

ビルドは不要です。`public/` を任意の静的サーバーで配信してください。

```bash
python -m http.server 8891 --directory public
```

http://localhost:8891 を開きます。

## テスト

```bash
node tests/calc.test.js
```

消費税の端数処理、複数税率の集計、源泉徴収の計算、登録番号の形式検証を検証します。
期待値は国税庁タックスアンサー(No.6625 / No.2795)に基づいています。

## 料金の考え方

**PDFの出力そのものは無料・透かしなしを維持します。** 課金は「1通作るのに必要な機能」ではなく、
「何度も作る人の手間を減らす機能」から頂く方針です(取引先・品目マスタの保存、自動採番と発行履歴、
見積書→請求書の変換、テンプレートの追加)。詳細は [docs/仕様.md](docs/仕様.md) を参照してください。
