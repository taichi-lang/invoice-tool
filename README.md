# 請求書ジェネレーター

インボイス制度(適格請求書)と源泉徴収に対応した、日本語の請求書作成ツールです。
**登録不要・ブラウザ内で完結**し、出力するPDFに透かしやロゴは一切入りません。

> 公開中(2026-07-31 にオーナー承認のうえ本番公開)。https://invoice-tool-kohl.vercel.app

## 特徴

- **透かしなしのPDF** — 無料のまま、取引先へそのまま送れる完成品を出力します
- **適格請求書に対応** — 登録番号欄と、税率ごとの区分集計を標準で備えます
- **端数処理は税率ごとに1回** — 明細行ごとには処理しません(インボイス制度の要件)。切り捨て / 四捨五入 / 切り上げを選べます
- **源泉徴収を自動計算** — 100万円以下 10.21%、100万円超 20.42%(復興特別所得税を含む)。行単位で対象・対象外を切り替えられます
- **入力内容を送信しない** — サーバーを持たず、すべて端末内で処理します
- **書き出し** — PDF(印刷)/ CSV(Excel対応)/ JSON(入力データの保存・再読込)
- **4種類の書類** — 請求書 / 見積書 / 納品書 / 領収書。`/?type=estimate` のように種別を指定して開けます
- **収入印紙の判定** — 領収書に貼る印紙を `/inshi` でその場で判定します。5万円の境界だけでなく、消費税額の区分記載・電子交付・クレジットカード、そして**免税事業者だけ結論が変わる点**まで扱います
- **実務の解説記事を同梱** — 書き方・計算方法の解説ページをツールとセットで持ち、検索からの入口にします

## 画面

左に入力フォーム、右にA4のリアルタイムプレビューを並べた2ペイン構成です。
「PDFとして保存 / 印刷」からブラウザの印刷ダイアログを開き、A4 1ページのPDFとして保存できます。

## 技術構成

依存パッケージ **0**、ビルド工程 **なし**の静的サイトです。

| 項目 | 内容 |
|------|------|
| フロントエンド | 素の HTML / CSS / JavaScript(ES2020) |
| PDF出力 | ブラウザの印刷機能(`@media print` によるA4レイアウト) |
| データ保存 | localStorage(端末内のみ) |
| ホスティング | Vercel(静的配信) |
| テスト | Node.js 標準の `assert` のみ |

## セットアップ

ビルドは不要です。`public/` を任意の静的サーバーで配信してください。

```bash
python -m http.server 8891 --directory public
```

http://localhost:8891 を開きます。

なお本番(Vercel)は `cleanUrls` を有効にしているため、記事のURLは `/guide/seikyusho-kakikata` のように
拡張子なしになります。上記のローカルサーバーは拡張子を省略できないため、
ローカルで記事を開くときは `/guide/seikyusho-kakikata.html` を指定してください。

## テスト

```bash
node tests/calc.test.js
node tests/stamp.test.js
node tests/print.test.js
node tests/links.test.js
```

合計 **49件**(calc 18 / stamp 17 / print 6 / links 8)。

`calc.test.js`(18件)は消費税の端数処理、複数税率の集計、源泉徴収の計算、登録番号の形式検証を扱います。
期待値は国税庁タックスアンサー(No.6625 / No.2795)に基づいています。

`stamp.test.js`(17件)は印紙税の判定を扱います。税額表の全区分は No.7141 の原文と照合しており、
**5万円ちょうどは課税**という境界と、**課税事業者と免税事業者で結論が変わる**ケースを固定しています。

`print.test.js`(6件)は、印刷時に合計欄と振込先がページをまたいで割れないための `break-inside: avoid` が
`@media print` の中に在り続けることを確かめます。

`links.test.js`(8件)はサイトの構造を固定します。**ツールが出せる4種類の書類(請求書・見積書・納品書・領収書)に、
それぞれ入口となるページが在ること**を含みます。2026-09-02 まで、納品書は出力できるのに入口が1つも無い状態でした。
